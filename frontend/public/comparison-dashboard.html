How these are computed

  • Daily P/L is summed by entry/open date; equity = capital + cumulative P/L. CAGR annualizes over the calendar span; Sharpe/Sortino use daily returns on running net-liq with a 4.3% risk-free rate, annualized ×√252. Max drawdown is peak-to-trough on the equity curve.
  • Recent windows are the last and calendar days relative to each book's most recent trade. Drift z-score = (recent avg P/L/trade − full-history avg) ÷ full-history per-trade stdev; > +1σ improving, < −1σ degrading. Rows with fewer than 3 recent trades are flagged low-n — treat as noise.
  • Bot → strategy resolves in tiers: exact live-name match → strategy-name containment → fuzzy token match → manual preset → own name (timestamps stripped). Edit any mapping below; changes persist in this browser and recompute strategy rollups live.
  • Accounts are aggregated — all 14 live accounts are treated as one book. The backtest's Backtick Name is ignored; Position Name is the bot key.
